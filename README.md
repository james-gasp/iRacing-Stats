See how your iRating stacks up against the field's actual lap times, per series, season, and track.

## How it works 
It pulls results from the official iRacing Data API and plots each driver's qualifying, fastest-race-lap, and average-race-lap times against their iRating, with a fitted pace curve so you can see roughly what lap time you "should" be running at a given iRating

Currently scoped to road series only, other categories will be added later
